# OpenDownload

Telegram Mini App / веб-приложение для сохранения видео и аудио по ссылке.

- YouTube — видео с выбором качества (144p…4K) и кодека (H.264 / VP9 / AV1)
- Аудио — MP3 / Opus / OGG / WAV с выбором битрейта (64…320 kbps)
- SoundCloud, TikTok, Instagram, X, VK, Reddit, Twitch Clips, Vimeo, Pinterest, Bilibili
- Загрузка внутри Telegram через нативный `downloadFile` (Bot API 7.6+), с откатом на внешний браузер

## Как это работает

Приложение само ничего не выкачивает с сервисов. Оно отправляет ссылку на **сервер cobalt**, а тот
возвращает прямую ссылку на файл. Поэтому нужен адрес такого сервера.

Адрес вводится **прямо в интерфейсе** — раздел «Настройки инстанса» внизу страницы. Он хранится в
localStorage браузера, так что ничего пересобирать и никаких переменных окружения задавать не нужно.
Рядом есть кнопка «Проверить связь»: она сразу скажет, отвечает ли сервер и какая у него версия.

## Главное про API-ключ

**У cobalt нет сайта, где выдают API-ключ.** Нет регистрации, личного кабинета и кнопки
«Get API key». Ключ — это строка, которую вы сами придумываете и записываете в конфиг своего
сервера; проверяет её только ваш сервер. Поэтому искать ключ на cobalt.tools бессмысленно —
сначала нужен сервер.

Если инстанс не требует авторизацию, поле «API-ключ» просто оставьте пустым.

## Где взять сервер бесплатно

### Вариант 1. На своём компьютере через Cloudflare Tunnel — 0 ₽, ~10 минут

Сервер работает на вашем ПК, а Cloudflare бесплатно даёт ему публичный HTTPS-адрес (это важно:
Telegram Mini App работает только по HTTPS, а `localhost` с сервера недоступен).

1. Установите [Docker Desktop](https://docs.docker.com/get-started/get-docker/).
2. Создайте папку и в ней файл `docker-compose.yml`:

```yaml
services:
  cobalt-api:
    image: ghcr.io/imputnet/cobalt:11
    restart: unless-stopped
    ports: ["9000:9000"]
    environment:
      API_URL: "http://localhost:9000/"
```

3. Запустите: `docker compose up -d`
4. Установите [`cloudflared`](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
   и выполните:

```bash
cloudflared tunnel --url http://localhost:9000
```

5. В консоли появится адрес вида `https://random-words.trycloudflare.com` — скопируйте его.
6. Впишите этот адрес в `API_URL` в `docker-compose.yml` (со слешем на конце) и перезапустите:
   `docker compose up -d`
7. Вставьте адрес в «Настройки инстанса» → «Проверить связь».

Минусы бесплатного туннеля: пока компьютер выключен, загрузки не работают, и адрес меняется при
каждом перезапуске `cloudflared`.

### Вариант 2. Бесплатный тариф хостинга — работает круглосуточно

Любой хостинг с Docker и бесплатным тарифом (Koyeb, Render и подобные). Разворачиваете образ
`ghcr.io/imputnet/cobalt:11`, открываете порт `9000`, в переменную `API_URL` вписываете выданный
домен. На бесплатных тарифах сервис засыпает без активности, поэтому первый запрос после паузы
идёт дольше обычного.

### Вариант 3. Готовый чужой инстанс

Список сообщества: <https://instances.cobalt.best>. Пользуйтесь только теми, чей владелец разрешил
публичный доступ. Именно из-за чужого закрытого эндпоинта сломалась первая версия сайта: она
обращалась к `api.cobalt.tools`, который авторы закрыли.

## Если нужен ключ (защита своего инстанса)

Ключ нужен, только когда вы открываете инстанс наружу и не хотите, чтобы им пользовались посторонние:

```yaml
environment:
  API_URL: "https://ваш-адрес/"
  API_KEY_URL: "file:///keys.json"
  API_AUTH_REQUIRED: "1"
volumes:
  - ./keys.json:/keys.json:ro
```

Сгенерируйте UUID командой `uuidgen` (или `python -c "import uuid;print(uuid.uuid4())"`) и положите
в `keys.json`:

```json
{
  "9b9d3c53-1e2f-4b6a-a7d3-8f1c2e5d4a90": { "name": "opendownload", "limit": 50 }
}
```

Этот UUID и вписывается в поле «API-ключ» в интерфейсе.

Полная документация по запуску: <https://github.com/imputnet/cobalt/blob/main/docs/run-an-instance.md>

## Инстанс по умолчанию для всех посетителей (необязательно)

Чтобы не заставлять каждого вводить адрес вручную, задайте переменные окружения проекта
(шестерёнка → Vars):

| Переменная | Назначение |
| --- | --- |
| `COBALT_API_URL` | адрес инстанса, например `https://cobalt.example.com` |
| `COBALT_API_URLS` | несколько адресов через запятую — перебираются по порядку |
| `COBALT_API_KEY` | ключ, если инстанс его требует |

Адрес из интерфейса имеет приоритет над этими переменными. Если один инстанс недоступен, исчерпал
лимит или отклонил ключ — сервер автоматически пробует следующий из списка.

## Другой бэкенд вместо cobalt

Если захотите коммерческий API (RapidAPI и подобные), правьте только `app/api/resolve/route.ts` —
весь сетевой код собран там:

- `payload` — что уходит в апстрим (`videoQuality`, `audioFormat`, `audioBitrate`, `youtubeVideoCodec`)
- `authHeader` в `lib/backend.ts` — схема авторизации (`Api-Key`, `Bearer`, `X-RapidAPI-Key`)
- блоки `data?.status === ...` — разбор ответа в общий формат `{ ok, kind, url, filename }`

Клиент менять не нужно.

## YouTube: приватные и 18+ видео

Для них инстансу нужны cookies YouTube — см. `cookies.example.json` в репозитории cobalt. Без них
приложение вернёт сообщение «YouTube требует авторизацию».

## Подключение к Telegram

1. `@BotFather` → `/newbot` → получите токен.
2. `/newapp` → выберите бота → укажите URL деплоя (Publish в v0 или Vercel).
3. `/setmenubutton` → кнопка меню, открывающая Mini App.

Тема Telegram подхватывается автоматически: `themeParams` мапятся в CSS-токены.

## Про Spotify и подобные сервисы

Spotify, Apple Music, Deezer, Tidal, Яндекс Музыка отдают аудио только в зашифрованном виде (DRM).
Обход этой защиты — не техническая задача, а нарушение условий сервиса и авторских прав, поэтому
такие ссылки приложение отклоняет с объяснением. Официальный Spotify Web API отдаёт только
метаданные и превью — если нужен поиск/плейлисты по метаданным, это можно добавить отдельно.

Для музыки используйте SoundCloud (многие авторы разрешают загрузку) и YouTube Music.
