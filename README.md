# OpenDownload

Telegram Mini App / веб-приложение для сохранения видео и аудио по ссылке.

Работает на **yt-dlp** и **ffmpeg** — оба open source, никаких внешних API, ключей и регистраций.

- Форматы приходят с сервера настоящие: реальные качества, кодеки и размеры файлов
- YouTube — от 144p до 4K, склейка отдельных дорожек видео + звук
- Аудио — MP3 320 / Opus / FLAC / WAV или исходная дорожка без перекодировки
- SoundCloud, TikTok, Instagram, X, VK, Reddit, Twitch, Vimeo, Bilibili и ещё ~1800 сайтов
- Загрузка внутри Telegram через нативный `downloadFile` (Bot API 7.6+), с откатом на браузер

## Как это работает

Никаких сторонних сервисов в цепочке нет:

1. `POST /api/info` — сервер запускает `yt-dlp -J`, разбирает список форматов и отдаёт их клиенту
2. `GET /api/download` — `yt-dlp` пишет файл в stdout, ответ стримится в браузер на ходу

Файлы не сохраняются на диск и не занимают место: поток идёт от yt-dlp сразу пользователю.

### Бинарники

`lib/binaries.ts` при первом запросе скачивает автономный `yt-dlp` (один файл, Python не нужен) в
системный temp-каталог и кеширует его. `ffmpeg` берётся из npm-пакета `ffmpeg-static`.

Если в системе уже есть свои сборки, укажите пути и скачивание отключится:

| Переменная | Назначение |
| --- | --- |
| `YTDLP_PATH` | путь к своему `yt-dlp` |
| `FFMPEG_PATH` | путь к своему `ffmpeg` |
| `YTDLP_COOKIES` | путь к `cookies.txt` для приватных и 18+ видео |

## Почему склеенные видео отдаются в MKV

Качества выше 360p на YouTube хранятся раздельно: видео без звука + звуковая дорожка. Их
склеивает ffmpeg. Контейнер MP4 держит индекс (`moov`-атом) в конце файла, поэтому его нельзя
дописать в потоке — в stdout получается битый файл. MKV потоковый по своей природе, поэтому
склейка идёт в него. MKV открывают VLC, современные плееры, Telegram и Android; для QuickTime на
Mac файл нужно переконтейнеризировать.

Одиночные форматы (360p и ниже, где звук уже внутри) отдаются как есть — в MP4.

## Ограничения

- **Время запроса.** На Vercel serverless-функция ограничена по длительности (на Hobby — 60 секунд,
  на Pro — до 800). Длинные видео в 4K могут не успеть. Локально или на своём сервере лимита нет.
- **IP датацентра.** YouTube иногда требует подтверждения, что запрос не от бота. Если появится
  «YouTube требует авторизацию» — подложите cookies через `YTDLP_COOKIES`.
- **Прямые эфиры** отклоняются: у них нет конца файла.
- **Обновление yt-dlp.** Сайты меняют разметку, поэтому движок обновляется часто. Удалите
  закешированный бинарник из temp-каталога, и он скачается заново.

## Как получить cookies (для приватных и 18+ видео)

1. Установите расширение для экспорта cookies в формате Netscape (`cookies.txt`).
2. Войдите в YouTube, экспортируйте файл.
3. Положите его рядом с проектом и укажите путь в `YTDLP_COOKIES`.

Файл содержит вашу сессию — не коммитьте его в репозиторий.

## Подключение к Telegram

1. `@BotFather` → `/newbot` → получите токен.
2. `/newapp` → выберите бота → укажите URL деплоя (Publish в v0 или Vercel).
3. `/setmenubutton` → кнопка меню, открывающая Mini App.

Тема Telegram подхватывается автоматически: `themeParams` мапятся в CSS-токены. Нативное
сохранение файла требует Bot API 7.6+, в старых клиентах ссылка откроется во внешнем браузере.

## Про Spotify и подобные сервисы

Spotify, Apple Music, Deezer, Tidal и Яндекс Музыка отдают аудио только в зашифрованном виде (DRM).
Обход этой защиты — не техническая задача, а нарушение условий сервиса и авторских прав, поэтому
такие ссылки приложение отклоняет с объяснением. Официальный Spotify Web API отдаёт только
метаданные и превью — если нужен поиск или плейлисты по метаданным, это можно добавить отдельно.

Для музыки используйте SoundCloud (многие авторы разрешают загрузку) и YouTube Music.

## Ответственность

Скачивайте только тот контент, на который у вас есть права: собственные загрузки, материалы с
открытой лицензией или файлы с разрешения автора.

## Запуск локально

```bash
pnpm install
pnpm dev
```

`ffmpeg-static` скачивает бинарник в `postinstall`. Если пакетный менеджер заблокировал скрипт,
выполните вручную:

```bash
node node_modules/ffmpeg-static/install.js
```

## Структура

| Файл | Назначение |
| --- | --- |
| `lib/binaries.ts` | получение и кеширование `yt-dlp` / `ffmpeg` |
| `lib/ytdlp.ts` | запуск `yt-dlp -J`, разбор форматов, тексты ошибок |
| `app/api/info/route.ts` | список доступных качеств для ссылки |
| `app/api/download/route.ts` | стриминг файла, склейка и перекодировка |
| `lib/services.ts` | распознавание сервиса по домену, блокировка DRM |
| `lib/use-telegram.ts` | тема, хаптика и сохранение файла в Telegram |
